    Per D3 (PLAT-02): create `src/Web/operator-ui/nginx.conf` — a minimal server on port 80 serving `/usr/share/nginx/html` with SPA fallback (`try_files $uri /index.html`), and two proxy locations:
    - `location /api/` → `proxy_pass http://shipment-api:5001;` (no URI part after the host so the full original path, including `/api`, is forwarded — the Shipment API serves its endpoints under `/api`).
    - `location /hubs/` → `proxy_pass http://tracking-api:5002;` with `proxy_http_version 1.1`, `proxy_set_header Upgrade $http_upgrade;`, `proxy_set_header Connection "upgrade";`, and a long `proxy_read_timeout` (e.g. 3600s) so SignalR WebSockets stay open.
    Also forward standard headers (`Host`, `X-Real-IP`, `X-Forwarded-For`).
    Create `src/Web/operator-ui/Dockerfile` with two stages:
    1. `node:24` build stage: WORKDIR /app; copy package.json + lockfile; `npm ci`; copy the rest of the project; `ng build --configuration docker` (the Task-1 configuration).
    2. `nginx:stable-alpine` runtime stage: copy `dist/operator-ui/browser` → `/usr/share/nginx/html`; copy nginx.conf → `/etc/nginx/conf.d/default.conf` (replacing the default site); EXPOSE 80.
    The compose healthcheck for this service (already defined in plan 06-01's compose file) uses `wget -qO- http://localhost/ > /dev/null` — the SPA fallback must make `GET /` return 200.
