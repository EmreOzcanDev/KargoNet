<objective>
Build the REST surface in Shipment.Api: `POST /api/shipments` (201 + `ShipmentDto`, 409 on duplicate), `GET /api/shipments` (all, ordered by `CreatedAt`), `GET /api/shipments/{trackingNumber}` (404 when absent), and `PUT /api/shipments/{id}/status` (200 + updated `ShipmentDto`, 404 when absent). Both write paths insert/update the `Shipment` and its `OutboxMessage` (`shipment.created` / `shipment.status.changed`, envelope serialized by the Phase 2 `EventSerializer`) inside a single EF transaction. Endpoints are proven end-to-end with `WebApplicationFactory` over the InMemory provider — no live DB, no broker.

Purpose: SC1/SC2/SC3. Atomicity is the core value — a committed shipment without its event would violate the no-lost-status-propagation guarantee, so the state mutation and the event row share one `BeginTransaction`/`Commit`.

Output: `ShipmentDto` + request records, the endpoint mapping, DI registration of `ShipmentDbContext`, and `ShipmentEndpointTests` covering create (atomicity + 409), both GETs (404), and status update (correct from/to payload).
</objective>

|----------|-------------|
| client → Shipment.Api REST endpoints | Untrusted request bodies (tracking number, description, destination, status) cross into the API |
| Shipment.Api → PostgreSQL (Phase 6) | EF transactions run against the production database |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-03 | Tampering | POST/PUT request bodies | medium | mitigate | `trackingNumber` is trimmed before insert; `status` is parsed against the closed `ShipmentStatus` enum (invalid names rejected, not stored as arbitrary strings); `description`/`destination` are length-capped by the model (64/256); all persistence is EF-parameterized |
| T-03-04 | Repudiation | write-path transaction | high | mitigate | Shipment mutation and OutboxMessage insert share one `BeginTransaction`/`Commit`; a failure rolls back both, so a shipment can never commit without its event — asserted by ShipmentEndpointTests (exactly one outbox row per write) |
| T-03-05 | Denial of Service | unauthenticated REST surface | low | accept | No auth by locked decision (per 03-CONTEXT.md); network-level access control is a Phase 6/compose concern |
</threat_model>
