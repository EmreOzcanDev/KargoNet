## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> Shipment/Tracking APIs | User-selected status values and tracking numbers cross from the SPA into upstream REST calls and hub group invocations |
| APIs/hub -> browser rendering | Untrusted JSON (shipment fields, `payloadJson`, hub broadcast payloads) is rendered into the DOM |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-04 | Tampering | `shipments.ts` / `timeline-drawer.ts` rendering | medium | mitigate | All API-sourced values render through Angular interpolation `{{ }}` (auto-escaped); no `[innerHTML]` binding anywhere in the new components; `payloadJson` is parsed only inside `try/catch` with the `eventType` text as the fallback |
| T-05-05 | Tampering | `tracking.service.ts` hub handling | medium | mitigate | `ShipmentUpdated` handlers validate the payload has a non-empty `trackingNumber` before touching the table; `dispose()` is idempotent and unsubscribes all streams so a destroyed component cannot leak the connection or group subscriptions (O2 acceptance) |
| T-05-06 | Information Disclosure | error handling (both components) | low | accept | Failed API/hub calls surface the fixed, detail-free banner/inline copy (`We couldn't reach the KargoNet service…` / `Couldn't update status — try again.`) — no URLs, payloads, or stack fragments rendered |
